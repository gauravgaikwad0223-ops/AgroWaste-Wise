# AgroWaste-Wise
AgroWaste Wise is a software prototype that helps users identify suitable agricultural waste reuse methods based on waste category and quantity.



AgroWaste Wise

Project Overview

AgroWaste Wise is a software prototype designed to support agricultural waste management by suggesting potential reuse methods based on the type and quantity of waste entered by the user.

The project promotes awareness about waste reduction, resource reuse, and sustainable agricultural practices.

Objectives

- Identify different categories of agricultural waste.
- Accept waste category and quantity as user inputs.
- Display possible reuse and management methods.
- Encourage sustainable utilization of agricultural residues.

Features

- Simple text-based user interface.
- Multiple agricultural waste categories.
- Quantity input in kilograms.
- Category-based reuse recommendations.
- Basic input validation.

Technologies Used

- Python
- JSON
- Visual Studio Code
- GitHub

Requirements

- Python 3.10 or later recommended.
- A code editor such as Visual Studio Code.

No third-party Python packages are required for this basic implementation.

How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open a terminal in the project directory.
4. Run the following command:

python main.py

5. Enter a waste category, such as "dry leaves".
6. Enter the quantity in kilograms.
7. Review the suggested reuse methods.

Limitations

- Recommendations are based on a predefined dataset.
- The prototype does not independently test waste composition.
- Suggestions are general and require practical assessment before implementation.
- The current version does not use live agricultural or market data.

Future Scope

- Add more agricultural waste categories.
- Develop a graphical user interface.
- Include regional waste management information.
- Improve recommendations using verified agricultural data.
